# GNSS-DC-Upload

A tool for loading a DC file from the command line to a Trimble GNSS receiver allowing for the use of local co-ordinates. 

This does not use an offical API, it just uses the same method as the WebUI.

Usage: ./DC_Upload.sh <DC_filename> [server_address] [password] [user]

The default user is password with a password of admin

The default server is gnss.local.
